# Incident Investigation — WF-001

**Project:** Wind Farm OT/SCADA Security Monitoring

**Incident date:** 3 November 2026

**Status:** Under investigation

## 1. Incident Summary

Wazuh detected repeated unauthorised requests targeting the WT-02 turbine power-limit configuration in the simulated wind farm.

Five authentication failures were correlated within the configured 60-second detection window.

The correlation generated Wazuh rule 100204 at severity level 12.
